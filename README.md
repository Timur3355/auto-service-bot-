# 🚗 AutoService Bot — Telegram-бот для автосервиса

Бот автоматизирует запись клиентов и расчет стоимости ремонта, снижая нагрузку на менеджеров.

## 💡 Бизнес-ценность
*   **+30% к записям:** Клиент может записаться 24/7 без звонка.
*   **Прозрачность цен:** Калькулятор сразу показывает примерную стоимость работ и запчастей.
*   **Автоматизация:** Уведомления администратору о новых записях приходят мгновенно.

## 🛠️ Стек технологий
*   **Python 3.10+**
*   **Aiogram 3** (асинхронный фреймворк)
*   **SQLite + aiosqlite** (хранение данных и записей)
*   **FSM** (машина состояний для многошаговых сценариев)

## ⚙️ Функционал
1.  **Каталог услуг:** Просмотр прайса с описанием.
2.  **Умный калькулятор:** Расчет итоговой суммы (работа + запчасти).
3.  **Онлайн-запись:** Выбор удобной даты и сохранение в БД.
4.  **Админ-панель:** Мгновенные уведомления о новых клиентах.

## 🚀 Как запустить
1.  Клонируйте репозиторий
2.  Установите зависимости: `pip install -r requirements.txt`
3.  Настройте `.env`: вставьте токен от @BotFather.
4.  Запустите: `python main.py`
